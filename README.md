## daftar ceklist

- Seluruh area setiap kartu bisa diklik dan langsung membuka data kategori yang sesuai.
- [ ]  Kartu bisa dipakai lewat keyboard (Tab lalu Enter), dan fokusnya kelihatan jelas.
- [ ]  Back browser dari halaman data kembali ke ringkasan; refresh di `#dipa` tetap di data DIPA.
- [ ]  Tiap kartu menampilkan jumlah dokumen dan tahun terbaru yang benar, atau "Belum ada dokumen".
- [ ]  Nggak ada link keluar (Drive atau PDF) di halaman; semua dokumen terbuka di viewer.
- [ ]  Viewer jalan di Chrome desktop, Safari iOS, dan Chrome Android.
- [ ]  Viewer bisa ditutup pakai Esc, fokus kembali ke tombol semula, dan terbaca pembaca layar.
- [ ]  Link `#dipa/12` bisa dibagikan dan langsung membuka viewer.
- [ ]  Keadaan loading, kosong, dan error tampil dengan benar.
- [ ]  Nggak ada overflow horizontal di lebar 360px dan 1366px (390px dan 768px juga kalau sempat).
- [ ]  Nggak ada teks contoh atau tanda `[...]` yang tersisa di halaman.
- [ ]  Teks isi minimal 0,95rem; kontras teks minimal 4,5:1.
- [ ]  Halaman lain di website tampilannya tetap sama (`styles.css` aman).
